# 좌석 선택 2단계 UX

## 목적

예매 사용자가 날짜와 회차를 먼저 확정한 뒤 좌석을 고르게 하여, 좌석 선택 중 금액과 결제 정보가 URL 조작에 의존하지 않도록 한다.

## 흐름

1. 날짜·회차·매수를 선택한다.
2. 좌석 선택 단계로 이동한다.
3. 실시간 좌석도 API가 성공하면 실제 구매 가능한 좌석 버튼에서 좌석을 명시적으로 선택한다.
4. API가 실패하거나 선택 가능한 좌석이 없으면 기본 좌석표를 fallback으로 표시한다.
5. 좌석 선택 전에는 결제 링크를 렌더링하지 않고 disabled 버튼만 표시한다.
6. 선택 완료 후 checkout에는 `date`, `time`, `seats`, `count`, `ticketId`만 전달한다.

## 운영 기준

- 좌석 자동 선택은 사용하지 않는다.
- `base`, `fee`, `total` 같은 금액 파라미터는 새 예매 흐름에서 전달하지 않는다.
- checkout은 과거 URL 호환을 위해 금액 파라미터를 읽을 수 있지만, 할인 역산이나 최종 결제 금액 신뢰 기준으로 쓰지 않는다.
- 예매 시간이 1분 이하로 남으면 별도 경고를 표시하고, 만료 시 재입장 링크를 제공한다.

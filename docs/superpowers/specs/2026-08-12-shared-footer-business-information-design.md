# 공통 푸터 사업자 정보 노출 설계

## 배경

PR #179는 요청된 사업자 정보를 홈페이지에만 표시했다. `dev.ticketground.co.kr/company`를 포함한 공통 페이지는 `SiteFooter`의 기본값이 비표시라서 같은 정보를 볼 수 없다.

## 목표

- 한국어 공통 페이지의 푸터 좌측 하단에 기존 사업자 정보와 고객센터 이메일을 표시한다.
- 홈페이지와 공통 페이지가 같은 `SiteFooter` 사업자 정보 DOM을 재사용한다.
- 영어, 일본어, 중국어 홈페이지에는 한글 사업자 정보가 섞이지 않도록 기존 명시적 로케일 조건을 유지한다.

## 설계

`SiteFooter`의 `showBusinessInformation` 기본값을 `true`로 변경한다. 공통 페이지는 별도 전달값 없이 사업자 정보를 표시하고, 다국어 홈페이지는 이미 `showBusinessInformation={locale === "ko"}`를 명시하므로 비한국어 로케일에서 계속 숨긴다.

페이지마다 표시 플래그를 추가하지 않는다. 호출부 누락 가능성을 만들고 동일한 정책을 여러 파일에 반복하기 때문이다. 루트 레이아웃으로 푸터를 이동하지도 않는다. 현재 페이지 셸 구조를 바꾸는 것은 이번 표시 오류를 고치는 데 필요하지 않다.

## 검증

- 기존 공통 경로 테스트를 반대로 바꿔 `/company`에서 사업자 정보와 이메일 링크가 보이는지 검증한다.
- 테스트를 구현 전 실패시킨 뒤 기본값 한 줄 변경으로 통과시킨다.
- 홈페이지와 다국어 홈페이지 회귀 테스트를 함께 실행한다.
- 빌드 후 `dev.ticketground.co.kr/company`를 데스크톱과 모바일 브라우저로 캡처해 배치와 한글 줄바꿈을 확인한다.

## 비범위

- 사업자 문구 변경이나 다국어 번역 추가
- 푸터 전체 재디자인
- 간편로그인, OAuth, 인증 환경변수 및 공급자 콘솔 설정

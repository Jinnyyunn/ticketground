# 좌석 디자이너 기준 동작 대조표

이 문서는 로그인된 기준 편집기에서 각 도구를 직접 열고 조작해 확인한 관찰 결과와 TicketGround 자체 구현의 대응 동작을 기록한다. 외부 워크스페이스 식별자, 차트 식별자, API 키는 기록하지 않는다. 제품은 외부 런타임이나 SDK를 사용하지 않는다.

## 편집기 셸

| 기준 동작 | 관찰값 | TicketGround 자체 구현 |
| --- | --- | --- |
| 상단 도구막대 | 높이 45px, 저장/미리보기/테마/실행 취소·다시 실행/스냅/라벨/정렬/반전/복제/복사/붙여넣기/삭제/도움말 | 동일 순서의 45px 도구막대와 실제 편집 명령 |
| 왼쪽 도구 레일 | 41px 레일, 35px 도구 버튼 | 동일 규격의 고정 레일과 하위 도구 메뉴 |
| 오른쪽 속성 패널 | 전체 336px, 내부 320px 시트 | 선택 객체·활성 도구에 따라 바뀌는 336px 속성 패널 |
| 캔버스 탐색 | 손 도구, 휠 이동, 커서 중심 확대, 전체 보기 | 손/Space 이동, 휠 이동, 보조키 확대, 전체 보기·확대·축소·배율 표시 |

## 생성·편집 도구

| 도구 | 직접 확인한 기준 동작 | TicketGround 자체 구현 및 자동 검증 |
| --- | --- | --- |
| 선택 `V` | 객체 선택·이동 | 선택, 이동, 다중 선택, 잠금 객체 차단 |
| 좌석 선택 `X` | 개별 좌석 선택 | 개별/추가 좌석 선택 |
| 브러시 `C` | 드래그 좌석 선택 | 드래그 추가, Alt 제거 |
| 같은 유형 `Z` | 같은 객체 유형 선택 | 같은 유형 일괄 선택 |
| 노드 `A` | 노드 이동, 변 추가, 보조 클릭 삭제 | 다각형·선·구간 행의 노드 추가/이동/최소 개수 보호 삭제 |
| 초점 `F` | 차트 초점 배치 | 초점 배치·이동과 게시 유효성 반영 |
| 행 `R` | 표준 행, 구간 행, 여러 행 | 세 모드, 5pt 좌석 간격, 14pt 행 간격, Shift 15도 |
| 구역 `S` | 노드식 다각형 구역 | 다각형 생성, 내부 행, 레이블·카테고리·층 속성 |
| 테이블 `E` | 원형 6석, 직사각형 상4/하4 | 원형·직사각형 생성, 네 면 의자 수와 크기 편집 |
| 부스 `B` | 기본 50×50 | 클릭·드래그 생성과 크기 편집 |
| 영역 `G` | 사각형·타원·다각형 | 세 형상과 수용 인원 편집 |
| 도형 `H` | 사각형·타원·다각형 | 세 형상, 채우기·테두리·불투명도·크기 편집 |
| 선 `L` | 다중 노드, Enter 완료, 보조 클릭 마지막 노드 제거, Shift 45도 | 동일 노드 흐름과 선 색상 편집 |
| 텍스트 `T` | 클릭 배치·문구 입력 | 문구, 크기, 굵기, 정렬, 색상 편집 |
| 이미지 `I` | PNG/GIF/JPEG/WEBP/SVG, 최대 10MB, 클릭·드롭 | 안전한 서버 정규화, 비율 유지 배치, 교체·크기·회전·불투명도·레이어·잠금 |
| 아이콘 `O` | 기본 40pt | 무대·입구·화장실·별 갤러리, 40pt 기본값과 색상·크기 편집 |
| 손 `Space` | 캔버스 이동 | 버튼과 Space 임시 이동 |

## 이미지로 시작하기와 공연장 적용

1. 새 좌석 배치도는 공연장을 먼저 선택한다.
2. 빈 캔버스 또는 도면 불러오기를 선택한다.
3. 도면은 PNG/JPEG/GIF/WEBP/SVG를 안전한 PNG 자산으로 정규화하며, 최대 10MB를 초과하거나 실행 가능한 SVG는 거부한다.
4. 도면 위 자동 좌석 감지 결과는 검토 후 확정하고, 이후 모든 좌석과 도형은 네이티브 객체로 계속 편집한다.
5. 게시를 누르면 초안을 먼저 저장하고 불변 게시 리비전을 만든 뒤, 선택한 공연장의 활성 좌석 배치도로 즉시 교체한다.
6. 자체 서비스 키는 `seat-chart:read` 범위, 만료, 1회 표시, 해시 저장, 호출량 제한을 적용해 게시 리비전을 읽는다.

## 외부 의존성 경계

- 외부 편집기 SDK, 런타임, 워크스페이스 키, 차트 키를 사용하지 않는다.
- 기준 사이트는 관찰과 품질 대조에만 사용한다.
- TicketGround 공연장, 초안, 게시 리비전, 자산, 서비스 키가 유일한 운영 데이터 원본이다.

# iOS 공개 미디어 제공 조건

## 목적

포스터와 좌석도는 공개 API와 별도의 E2 공개 미디어 원본이 확인된 경우에만 원격으로 표시한다. 앱은 API 포트에서 미디어 포트를 추측하지 않으며, HTTP와 승인되지 않은 원본은 대체 화면으로 처리한다.

## 필요한 계약

- `TICKETGROUND_ASSET_BASE_URL`에 설정할 HTTPS 원본을 제공한다.
- 카탈로그의 상대 이미지 경로와 좌석도의 상대 이미지 경로가 그 원본에서 해석되어야 한다.
- 포스터는 `image/avif`, `image/webp`, `image/png`, `image/jpeg`, `image/gif` 중 하나를 반환한다.
- 좌석도 SVG는 `image/svg+xml`을 반환한다.
- 리디렉션은 HTTPS의 같은 원본·같은 포트만 허용한다.
- 공개 응답은 인증 쿠키나 사용자 자격 증명을 요구하지 않고, 적절한 캐시 헤더를 제공한다.

## 인수 증거

1. 대표 포스터 URL의 2xx 상태와 이미지 콘텐츠 유형.
2. 대표 SVG 좌석도 URL의 2xx 상태와 `image/svg+xml` 콘텐츠 유형.
3. 다른 원본, 다른 포트, HTTP 리디렉션이 앱에서 차단되는 결과.
4. 설정 누락, 잘못된 MIME, 손상된 파일에서 포스터·좌석도 대체 화면이 보이고 실패 응답이 캐시되지 않는 결과.

## 앱 동작

E2가 없으면 앱은 로컬 대체 이미지와 안내를 사용한다. 외부 4173 포트나 API 원본을 미디어 원본으로 자동 변환하지 않는다.

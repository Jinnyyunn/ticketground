# seats.io Designer Full Feature Parity Spec

Target: https://www.seats.io/demos/designer/demoChartLargeTheatre2D  
Implementation: `/admin/seat-designer`

## Tools (must all be usable)

| Tool | Shortcut | Required behavior |
|------|----------|-------------------|
| Select | V | Click select, shift multi, marquee, drag-move |
| Select seats | X | Click individual seats |
| Brush | C | Drag over seats to multi-select |
| Same type | Z | Select all objects of clicked type |
| Node | A | Show/edit polygon vertices on section/area |
| Focal | F | Click to set focal point |
| Row | R | Two-click row; inspector seat count/curve |
| Section | S | Multi-click polygon; double-click finish |
| Table | E | Click place round table with seats |
| Booth | B | Drag rectangle booth |
| Area | G | Multi-click GA area; capacity editable |
| Rectangle | H | Drag decorative rect |
| Line | L | Two-click line |
| Text | T | Click + prompt label |
| Image | I | Click + file picker, place image |
| Icon | O | Click place icon (stage/entrance/wc/star) |
| Hand | SPACE | Pan canvas |

## Toolbar

Save, Preview, Theme, Undo/Redo, Snap, Section contents, Labels, Align, Flip H/V, Duplicate, Copy/Paste, Delete, Zoom, Floor, JSON export, Valid

## Layers

All / Foreground / Interactive / Background / Surroundings

## Inspector

Chart summary, categories manage, validation, selection properties (label, category, seat count, capacity, curve, etc.)

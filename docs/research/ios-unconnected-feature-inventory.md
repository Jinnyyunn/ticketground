# iOS 미연결 메뉴와 외부 조건

| 기능 | 현재 앱 동작 | 필요한 계약 또는 외부 조건 |
| --- | --- | --- |
| 지역별 공연 | 계약 부재 안내와 홈 이동 | 지역 DTO와 공개 조회 경로 |
| 아티스트 | 계약 부재 안내와 홈 이동 | 아티스트 DTO와 공개 조회 경로 |
| 티켓오픈 캘린더 | 계약 부재 안내와 홈 이동 | 공개 오픈 일정 DTO와 조회 경로 |
| 회원가입·제공자 로그인 | HTTPS/OAuth 조건 안내, 계정 생성 안 함 | HTTPS API와 제공자 OAuth(E3) |
| 마이페이지·관심공연·문의 | 로그인 또는 HTTPS 필요 안내 | 짝지어진 사용자 세션과 HTTPS 사용자별 API |
| 좌석 현황 | 공개 읽기 전용 표시 | 카탈로그·좌석도 공개 계약 |
| 결제·예약·취소·양도·전송 | 거래 미지원 안내, 요청 안 함 | HTTPS, 인증, 결제·거래별 서버 계약(E3) |
| 기기 신뢰·푸시·QR | 실행하지 않음 | 기기 증명, 푸시, QR 신뢰 계약(E3) |
| 관리자 기능 | 앱 경로로 제공하지 않음 | 사용자 앱 범위 밖 |

앱은 기능마다 위 사유를 구분해 표시하며, 관리자 포트, 토큰, 사용자 식별자 같은 내부 정보는 화면이나 문서에 표시하지 않는다.

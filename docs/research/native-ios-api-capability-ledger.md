# iOS 서비스 연결 현황

기준일: 2026-08-02. `GET /api/native/v1/contract`의 응답 버전은 `1`이며 iOS는 이 계약과 HTTPS를 함께 확인한 뒤에만 사용자 자격 증명을 전송한다.

| 기능 | 서버 계약 | iOS 시뮬레이터 | 운영 상태 |
|---|---|---|---|
| 공개 카탈로그·지역·아티스트·오픈 캘린더 | 완료 | 완료 | HTTPS 도메인 배포 필요 |
| 프로필·예매내역 | principal 소유권 계약 완료 | 조회·빈 상태·수정 실패 확인 | 완료 |
| 관심공연 | idempotency·롤백·알림 취소 완료 | 성공·빈 상태·실패 롤백 확인 | 완료 |
| 고객센터 | 공개 FAQ·본인 문의/답변 완료 | 성공·빈 상태·로딩·실패 확인 | 완료 |
| 예매 세션 | 대기열·좌석 snapshot·hold·결제 전 draft 완료 | 충돌·만료·재연결 확인 | 결제 승인 이후는 제외 |

| 모바일 티켓 QR | 20초 서명·이전 QR 폐기·게이트 인증·동시 스캔 1회 consume·원문 비저장 완료 | 유효·만료·사용·취소·오프라인 확인 | 게이트 키 배포·장비 연동 필요 |

## 보안 경계

- 관리자 서비스는 `127.0.0.1:50084`에만 바인딩하고 iOS 구성에 포함하지 않는다.
- 사용자 API의 bearer credential은 HTTPS에서만 전송한다.
- QR 원문, 푸시 토큰, bearer credential, 게이트 키는 로그·fixture·증거 파일에 저장하지 않는다.
- 결제 프로그램 연동과 결제 승인/환불/정산 상태 전이는 이번 범위에서 제외한다.

# iOS 서비스 연결 현황

앱 메뉴의 `서비스 연결 현황` 화면은 현재 확인된 공개 API 계약만 안내한다. 내부 화면 경로이며, 웹 또는 API 경로를 추가하지 않는다.

## 공개 상태 조회

- `GET /api/state`만 현재 공개 읽기로 확인되었다.
- 상태 응답은 시도할 수 있다.

## 확인되지 않음 또는 이용 불가

- 공연 목록과 그 밖의 공개 읽기는 계약이 확인되지 않았다.
- `GET /api/catalog`도 현재 공개 읽기로 표시하지 않는다.

## HTTP 전용, 인증 또는 외부 계약이 필요함

- 로그인과 계정, 관심공연과 고객센터는 HTTP 전용 연결 또는 인증이 필요하다.
- 예매, 결제, QR, 외부 로그인 제공자는 외부 계약이 필요하다.
- 앱은 위 기능을 실행하거나 라이브라고 표시하지 않는다.
